# Ad creatives can't be edited
A creative's text, headline, link and button are fixed once made. Changing any of them means a new creative, and the new
post starts from zero likes, comments and shares. So it's always "keep the momentum" OR "new copy", never both: say which
one you're choosing and why. To reuse a winner elsewhere, reuse its creative ID or post ID (`effective_object_story_id`)
instead of uploading it again, and never run one post in two campaigns at once.
