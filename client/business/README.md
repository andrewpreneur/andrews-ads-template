# Second Brain
The business facts the agent reads before any strategy call. Fill these in during setup (step 4); Claude can interview you
and write them up. Keep them current: when an offer, price or result changes, update the file.
`identity.md` · `brand-voice.md` · `ideal-client.md` · `offers.md` · `economics.md` · `competitors.md` · `design.md`
If you keep a Google Drive "Second Brain" instead, put its folder link in `client/config.json` → `links.secondBrainFolder`.
