# Reports
- `YYYY-MM-DD.md`: the daily report (spend, results, tier per ad set, changes with proof, what's waiting on the owner).
- `YYYY-MM-DD-changes.md`: every change made in Meta that day, with the owner's approval quote for 8+ changes and the read-back.
- `YYYY-MM-DD-creative-checks.md`: the 4 creative checks for each new creative.
Never put customer names, emails or phone numbers here: totals only.
